# PAV Releases

PAV 个人资产版本管理器的公开发布仓库。这里仅分发程序、最终用户说明、许可证与稳定更新清单；源码保存在私有仓库。

## 当前版本

[下载 PAV 0.5.7](https://github.com/ZhaoJiusi/pav-releases/releases/tag/v0.5.7) · Windows 10/11 x64 便携版。

下载完整 ZIP，解压后运行 `PAV_Client.exe`。首次使用配置说明随包提供。

本版优化图标、文字、忽略状态、日志及窗口布局，整理工作区管理和设置入口，保留原有提交、更新、备份与恢复功能。原版本发布文件保留。

## 更新

在软件中选择“帮助 → 检查软件更新”。发现兼容的新版本后自动下载并校验，由用户确认退出安装。稳定通道清单位于根目录 `update.json`，无需登录 GitHub。

## 校验与签名

当前沿用未签名自用发布方式；主程序和更新器没有 Windows 代码签名，系统可能显示未知发布者提示。请从本仓库 Release 下载，并使用同一发布页的 `.sha256` 文件检查 ZIP。SHA-256 用于核对文件完整性，不能替代代码签名。

公开仓库和发布包不包含账号凭据、用户文件或本机配置。
